# 푸른 순환 (Blue Cycle)

> 손대지 않아도 먹이사슬이 저절로 돌아가는, 구경 중심의 방치형 생태계 수족관

**라이브 데모:** https://sigco3111.github.io/blue-cycle/

![version](https://img.shields.io/badge/version-1.9-blue)

## 소개

**푸른 순환**은 브라우저 안에서 살아 움직이는 작은 생태계입니다. 조류와 수초가 빛과 영양염으로 자라고, 초식어가 조류를 먹고, 포식자가 초식어를 사냥하고, 새우가 바닥을 청소하며, 해파리가 조류를 걸러 먹고, 가끔 그림자 같은 대형 포식자가 나타나 포식자까지 노립니다. 죽은 생물은 바닥에 가라앉아 분해되고, 다시 영양염이 되어 조류를 키웁니다. 이 순환이 닫혀 있어서, 아무 조작 없이 켜 두기만 해도 수족관이 스스로 유지됩니다.

## 플레이 방법

- **기본은 관람** — 페이지를 열어 두면 생태계가 알아서 돌아갑니다
- **화면 터치/클릭** — 선택해 둔 종류의 먹이를 그 자리에 뿌립니다
- **먹이 버튼** — 종류별 먹이 팔레트를 엽니다. 🌿 조류 먹이(초식어), 🥩 고기 먹이(포식자·대형), 🍂 바닥 먹이(새우), ✨ 플랑크톤(해파리)의 4종류가 있고, 맞는 먹이를 먹은 종은 약 반나절 동안 산란이 쉬워집니다. 고기 먹이를 먹은 포식자는 그동안 사냥을 쉬어 초식어에게도 휴식이 됩니다
- **자동 먹이(위임)** — 기본으로 켜져 있습니다. 방치해 두어도 굶는 종이 없도록 수족관이 스스로 가장 배고픈 종을 골라 알맞은 먹이를 뿌립니다(종류별 0.6일 간격). 팔레트의 🤖 버튼으로 끄고 직접 챙길 수도 있습니다
- **일시정지 / 1×·2×·4×** — 시뮬레이션 속도를 조절합니다
- **두 번째 수조 · 연결 수로** — 🛁 버튼에서 2호 수조를 개방하면 두 개의 생태계가 나란히 돌아갑니다. 연결 수로가 열려 있으면(기본) 붐비는 쪽의 개체가 반나절에 한 번꼴로 알아서 건너가고(이름·혈통·유전자 그대로), 개체 카드의 「⇄ 옮기기」로 직접 이주시킬 수도 있습니다. 수조 관리 창과 대시보드 「수조 비교」에서 두 수조의 개체 수·생물량·산소·수온·누적 기록을 나란히 비교합니다. 2호 수조는 에메랄드 라군 테마가 기본입니다
- **지표 버튼** — 생태계 대시보드를 엽니다 (환경 상태·환경 추이, 개체수 추이 그래프, 생물량 파이차트, 세대·기록, 관찰 일지)
  - `…/blue-cycle/#dash`로 열면 대시보드가 펼쳐진 상태로 시작합니다
- **낮밤 주기** — 하루 45초. 낮에는 빛줄기와 광합성, 밤에는 어두워지고 발광 플랑크톤이 떠다닙니다
- **수온·용존 산소** — 낮에 데워지고 밤에 식는 수온, 광합성과 호흡이 오가는 산소. 물고기 대사에 직접 영향을 줍니다
- **환경 이벤트** — 영양염이 쌓인 한낮에는 조류 대발생, 먹이망이 흔들리면 멸종과 회복(외부 유입)이 일어나고 관찰 일지에 기록됩니다
- **도감** — 색·크기·속도 조합이 새로운 형태로 태어나면 자동 등록됩니다 (흔함/드묾/희귀/전설 등급, 첫 발견일·누적 마리 수)
- **개체 검사** — 물고기·새우·해파리를 터치하면 이름·희귀도·세대·나이·에너지·유전자 수치가 뜨고 선택 링이 따라다닙니다. 빈 물을 터치하면 기존처럼 먹이를 뿌립니다
- **계절 · 장기 이벤트** — 12일마다 계절이 바뀝니다(48일 순환). 🌸 봄 산란기에는 번식이 왕성해지고, 🌞 여름 번영기에는 조류가 무성해지며, 🍂 가을 풍요기에는 대사가 느려져 먹이 부담이 줄고, ❄️ 겨울 인내기에는 수온이 내려가 번식이 드물어집니다. 여름에는 「적조」, 겨울에는 「한파」가 며칠간 들이닥치기도 합니다 — 개입할 필요는 없고, 지나가면 생태계가 스스로 돌아옵니다. 계절마다 물빛이 은은히 달라지고, HUD·대시보드 「환경 상태」에 현재 계절과 이벤트가 표시되며, 계절의 전환과 이벤트의 시작·끝은 연대기에 새겨집니다
- **혈통 계보도** — 대시보드 「혈통 계보도 · 시간의 흐름」에 모든 혈통의 여정이 시간축 위에 그려집니다. 흘러들어와 대를 세운 순간부터 지금까지(또는 대가 끊긴 순간까지) 한 줄의 궤적으로 — 살아 있는 혈통은 밝은 점으로, 끊긴 혈통은 흐린 선과 ✕로, 최고 세대가 함께 표시됩니다. 겨울에 꺾이고 봄에 새로 싹트는 가계의 흥망이 한눈에 보입니다
- **타임랩스** — 📹 버튼 한 번에 15초 × 8배속(약 2.7일 분) 녹화. 수족관의 낮밤과 계절, 무리의 흥망이 짧은 영상이 되어 미리보기·저장·공유 시트로 보낼 수 있습니다. 서버 없이 브라우저의 MediaRecorder로 만들어지며(webm/mp4 자동 선택), 지원하지 않는 브라우저에서는 정직하게 알려줍니다
- **도감 정리** — 수집이 200종 가까이 늘어나도 찾기 쉽게. 이름·초성 검색(「ㅊㅅㅇ」만 쳐도 초식어가 검색됨), 종류(초식어·포식자·새우·해파리·대형) 칩 필터, 등급(흔함·드묾·희귀·전설) 칩 필터, 등급/최근 발견/먼저 발견/많이 본/이름 순 정렬. 카드의 ☆를 누르면 즐겨찾기(기기에 보관, 「★ 즐겨찾기만」 칩으로 모아보기). 조합해서 쓸 수 있고 결과 수가 「n/전체종」으로 표시됩니다
- **가벼운 화면 갱신** — 대시보드의 도감·업적·가계·연대기·일지와 개체 카드는 내용이 바뀔 때만 다시 그립니다. 오래 키워 수집이 쌓여도(도감 150종+) 화면이 무거워지지 않습니다 — 생태계 시뮬레이션과 그림은 그대로
- **수족관 이야기** — 모든 생명에게 이름이 생깁니다. 흘러들어 온 야생 개체는 새 혈통(「별나가」)을 세우고, 후손은 그 가계를 잇습니다. 혈통의 정착·희귀 변이 탄생·대가 끊기는 순간·생존 이정표가 「수족관 연대기」에 쌓이고, 물고기를 터치하면 이름과 가계를 볼 수 있습니다 — 대시보드 「가계」에서 지금 살아 있는 혈통도 한눈에
- **사진 모드** — 📸 버튼 한 번에 수족관 장면을 PNG로. 생존일·도감·업적·최고 세대가 적힌 기록 카드를 함께 합성(켜고 끌 수 있음). 저장하거나 공유 시트로 바로 보낼 수 있습니다 — 셔터 소리는 덤
- **도전 과제** — 끝이 없는 수족관에 쌓이는 기록. 생존 일수(7·30·100일), 희귀·전설 발견, 도감 25·50·100종, 여섯 생명의 공존, 첫 장식·장식 10개, 10세대 도달, 대발생·회복 경험 등 16개 업적. 달성하면 금색 토스트와 팡파르가 울리고 관찰 일지에 남습니다. 현황은 대시보드 「도전 과제」 패널에서 — 저장 슬롯에 함께 보관됩니다
- **사운드** — 외부 파일 없이 WebAudio로 실시간 생성되는 물소리 앰비언스. 낮에는 밝은 물결과 물방울 소리, 밤에는 낮은 울림과 드문 반짝임으로 서서히 교차합니다. 사냥 성공 시 낮은 타격음, 희귀·전설 변이 발견 시 차임, 먹이를 뿌리면 첨벙 소리가 납니다. 첫 터치 이후에 시작되고(모바일 자동재생 정책), 🔊 버튼으로 음소거, 슬라이더로 음량 조절 — 설정은 기기에 저장됩니다
- **꾸미기 버튼** — 꾸미기 모드가 열리고, 바닥을 터치해 바위·산호·수초를 배치합니다 (각 8·8·10개 한도, 지우기 도구로 회수). 바위·산호 반경 60px는 **은신처**가 되어 그 안의 개체는 사냥 대상에서 빠집니다. 심은 수초는 산소를 만들고 조류 포자를 흘립니다. 「배경」 버튼으로 심해 블루·에메랄드 라군·황혼 바다 3가지 테마를 바꿀 수 있습니다. 배치와 테마는 저장 슬롯에 함께 보관됩니다
- **저장 버튼** — 3개 슬롯에 수족관 상태(개체·환경·도감·일지)를 저장하고 불러올 수 있습니다. 15초마다 자동 저장
- **오프라인 정산** — 접속하지 않은 시간(최대 8시간)을 시뮬레이션으로 따라잡아 돌아왔을 때 변화를 요약해 보여줍니다
- **새 수족관** — 저장 관리에서 현재 슬롯을 초기화하고 처음부터 다시 시작할 수 있습니다
  - `…/blue-cycle/#dash`로 열면 대시보드가 펼쳐진 상태로 시작합니다

## 시뮬레이션 구조

| 단계 | 역할 |
|---|---|
| 생산자 | 수초가 영양염을 소모하며 자라고, 조류 포자를 방출합니다 |
| 조류 | 부유하며 초식어와 해파리의 기본 먹이가 됩니다 |
| 초식어 | 배가 고프면 조류를 찾아다니고, 에너지가 차면 번식합니다 |
| 새우 (v0.7) | 바닥권에 사는 청소부. 찌꺼기를 주워 먹고 소화 잔여분을 즉시 영양염으로 돌려보내 순환을 빠르게 합니다. 굶주리면 조류를 쪼아 먹고, 포식자의 보조 먹이가 되기도 합니다 |
| 해파리 (v0.7) | 박동으로 떠다니며 닿는 조류를 천천히 흡수하는 필터 피더. 대형 포식자의 주요 먹잇감입니다 |
| 포식자 | 초식어를 사냥하며 개체수 균형을 잡습니다. 초식어가 부족하면 새우를 노립니다 |
| 대형 포식자 (v0.7) | 최상위 사냥꾼. 포식자·해파리·초식어·새우 순으로 노리지만, 한 번 먹으면 한동안 포만감으로 쉬고 먹이가 귀한 군집은 건드리지 않습니다. 수족관이 무르익으면 어디선가 나타납니다 |
| 분해 | 죽은 개체는 찌꺼기가 되어 가라앉고, 영양염으로 되돌아갑니다 |

모든 물고기는 **개체 단위**로 시뮬레이션됩니다. 에너지, 허기, 나이와 함께 크기·속도·색의 **유전자**를 가지며, 번식 시 부모를 닮되 가끔 변이가 생깁니다.

환경 변수로 **영양염**과 **산소**, **수온**, **낮밤(일광)**이 동작합니다. 낮에는 조류·수초가 광합성으로 산소를 만들고, 밤에는 물고기 호흡이 산소를 갉아먹습니다. 찌꺼기가 쌓이면 영양염이 올라 다시 생산자를 밀어 올리고, 영양염이 풍부한 한낮에는 조류가 대발생하기도 합니다. 포식 압력이 과도하면 초식어가 멸종하고, 포식자가 줄어든 뒤 외부에서 새 무리가 흘러들어 회복합니다. 유전자는 세대마다 약하게 평균으로 회귀해 대사 비용 폭주 없이 수십 일(실시간 수십 분)을 스스로 유지합니다.

## 기술

- 빌드 없는 순정 HTML + Canvas 2D 단일 파일 (`index.html`)
- 척추 곡선 기반 절차적 수영 애니메이션 — 물고기마다 진행파로 몸이 휘어진다
- 수면 파도 밴드와 반짝임, 깜빡이는 빛줄기, 바닥 코스틱스, 플랑크톤 입자
- 깊이별 색 보정 — 깊을수록 어둡고 푸르게
- 공간 해시 기반 이웃 탐색 — 개체가 늘어도 부하가 선형으로 유지
- 물고기는 이미지 에셋 없이 절차적 애니메이션으로 렌더링
- v0.6부터 `localStorage` 3슬롯 저장 — 저장 데이터가 손상되면 자동 격리하고 안전하게 새 수족관으로 시작합니다
